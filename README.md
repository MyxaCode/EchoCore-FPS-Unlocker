# EchoCore FPS Unlocker

Removes the 60 FPS cap in the EchoCore client.

- Works only with EchoCore installed in `%LocalAppData%\EchoCore`
- Does not touch Roblox or any other program
- Runs in the tray: right-click the icon to pick an FPS cap or exit

Based on [rbxfpsunlocker](https://github.com/axstin/rbxfpsunlocker) by axstin (MIT).

## Build

Open `rbxfpsunlocker.sln` in Visual Studio and build `Release|x64`.
